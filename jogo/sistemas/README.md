# Sistemas compartilhados

- `controles.js/css`: detecção de toque, escolha manual de celular/computador, preferência persistida e evento para neutralizar comandos ao mudar de modo. Funciona na sessão quando o armazenamento é bloqueado.
- `icones.js`: ilustrações próprias para gota, fogo, pata, mão de Kai, folhas, equipamentos e reciclagem. Flora usa sua identidade visual do jogo.
- `progresso.js`: reúne as conquistas das cinco fases, fragmentos e próximo destino, sem apagar as fases concluídas.
- `arte-manifesto.js` e `arte.js`: resolvem as artes originais para suas versões WebP. Dimensões e transparência permanecem iguais, mantendo os recortes das animações.

Os menus novos ficam em `../../tela-inicial/campanha/`. Configurações contém ajustes; Sobre o jogo reúne história, instruções, missões e ideias para cuidar da natureza.
