# Código do jogo

Esta pasta reúne os componentes da jogabilidade para as futuras fases de plataforma. As telas do menu continuam em `../tela-inicial/`, e as artes compartilhadas em `../assets/`.

O primeiro componente é [`controles/`](controles/README.md): joystick, botão com Kai pulando e ação de usar/interagir. Há um treino em **Sobre o jogo → Como jogar**. As seis missões ainda estão em desenvolvimento; o treino não altera o progresso do mapa.
