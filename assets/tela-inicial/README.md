# Artes da tela inicial

`floresta-menu.png`: ilustração de fundo gerada a partir da referência enviada pelo usuário. Título, botões, ícones e folhas da interface são elementos HTML/CSS/SVG separados e clicáveis.

`lilita-one.ttf`: Lilita One, distribuição do Google Fonts (`https://github.com/google/fonts/tree/main/ofl/lilitaone`). Licenciada pela SIL Open Font License 1.1; consulte `OFL-Lilita-One.txt`.

Todos os arquivos são locais. O menu não faz requisições a serviços de imagens, fontes ou áudio.
