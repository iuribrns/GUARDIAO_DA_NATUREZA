# Flora — ícone do jogo

Ícone de aba com o rosto da Flora: penas marrons, face clara, olhos âmbar, bico dourado e o detalhe verde do seu colar de folhas. A arte foi criada com base na Flora de `../../tela-inicial/assets/floresta-menu.png` e tem fundo transparente.

- `flora-original.png`: arte original gerada, preservada para futuras exportações.
- `flora-16.png`, `flora-32.png` e `flora-48.png`: tamanhos de aba do navegador.
- `favicon.ico`: inclui 16, 32 e 48 px para navegadores de computador.
- `flora-180.png`: ícone para atalhos da tela inicial do iOS.

As versões menores são exportações da mesma arte. Todas as cinco páginas HTML do jogo apontam para estes arquivos, com caminhos relativos que também funcionam quando o repositório é servido em uma subpasta. O parâmetro `v=flora-1` identifica esta versão do ícone para o cache do navegador.
