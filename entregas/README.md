# Downloads

[Baixar a pasta de arquivos JavaScript (.zip)](https://github.com/iuribrns/GUARDIAO_DA_NATUREZA/raw/refs/heads/main/entregas/guardiao-javascript.zip)

O pacote preserva os 309 arquivos `.js`, `.mjs` e `.cjs` reunidos antes da reorganização. Ele é uma entrega de código, não um jogo independente: HTML, CSS e imagens continuam necessários. Para a organização atual dos fontes, use a pasta `jogo/` deste repositório.

Para jogar, use o [GitHub Pages](https://iuribrns.github.io/GUARDIAO_DA_NATUREZA/). Para preparar o site atual, execute `npm run build` e utilize a pasta `dist/` gerada. Os pacotes de entrega não entram na publicação do jogo.
