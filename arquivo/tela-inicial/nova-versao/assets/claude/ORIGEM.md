# Artes aproveitadas do ZIP do usuário

Copiadas sem alteração de `GUARDIAO_DA_NATUREZA-atualizado.zip`, pasta `GUARDIAO_DA_NATUREZA-main/tela-inicial/animada/assets/`:

- `jogar.webp`
- `sobre.webp`
- `gear.webp`

`jogar.webp` e `sobre.webp` são usados como aparência de links HTML com rótulos acessíveis. `gear.webp` foi preservado como referência; o botão de configurações usa agora uma engrenagem SVG geométrica, sem deformações do sprite. Se uma imagem falhar, o desenho anterior em CSS continua disponível.

O fundo e os recortes animados de personagens do ZIP não foram incorporados: havia áreas preenchidas/esticadas no fundo e partes do cenário nos sprites que apareciam ao movê-los. O cenário limpo e o título aprovados foram preservados, assim como o pedido de manter Kai e Flora estáticos e a mochila removida.
