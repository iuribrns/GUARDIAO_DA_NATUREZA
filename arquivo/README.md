# Arquivo histórico

Aqui estão as versões anteriores, os materiais de criação e os testes que deixaram de fazer parte do fluxo atual. Os arquivos foram movidos mantendo seus nomes e conteúdos; não foram descartados nem recomprimidos.

| Pasta              | Material preservado                                                               |
| ------------------ | --------------------------------------------------------------------------------- |
| `desenvolvimento/` | Fontes de arte, preparadores, laboratórios e verificações de revisões anteriores. |
| `jogo/`            | Controladores substituídos, protótipos e documentação histórica.                  |
| `tela-inicial/`    | Telas e experiências anteriores do menu.                                          |
| `assets/`          | Artes originais que não são usadas pelo fluxo publicado.                          |

**Para jogar ou desenvolver a versão atual, volte ao [README principal](../README.md).** Esta pasta não é copiada para o GitHub Pages e não é servida pelo servidor de desenvolvimento.

Os caminhos citados no material histórico refletem a organização da época. Esses roteiros e testes não são a suíte atual. Para consultar a árvore original completa, use o commit `b420891` anterior à reorganização. O [registro da mudança](../desenvolvimento/organizacao/plano.json) informa o caminho antigo, o novo e o SHA-256 de cada arquivo. `npm run audit:files` confere que seus conteúdos continuam idênticos.

Mover arquivos facilita encontrar o código atual, mas não elimina os dados do histórico do Git. As imagens originais foram mantidas para preservar o trabalho de criação.

O laboratório tem um `package.json` próprio para suas dependências opcionais (Phaser e GSAP). Elas não são necessárias para instalar, compilar ou jogar a versão atual.
